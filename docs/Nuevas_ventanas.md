Lista de cambios a realizar a la ventana

Agregar presupuesto: Incluir un campo para que el usuario indique cuánto dinero tiene disponible para gastar en comida.

Agregar tipos de comida: Incorporar casillas de selección para elegir entre comida mexicana, italiana, japonesa, rápida, saludable, entre otras.

Agregar preferencias alimenticias: Permitir seleccionar opciones como vegetariana, vegana, sin gluten o sin lactosa.

Agregar zona de búsqueda: Incluir un campo donde el usuario indique la ubicación en la que desea buscar comida.

Agregar botón de limpiar: Permitir borrar los datos ingresados para realizar una nueva búsqueda.

Reorganizar la interfaz: Distribuir los campos y botones para que el formulario sea más claro, ordenado y fácil de utilizar.

Breve reflexión

Estos cambios apoyan la idea del proyecto porque permiten conocer mejor las necesidades y preferencias de cada usuario. Al recopilar información sobre su presupuesto, gustos alimenticios y ubicación, la aplicación podrá ofrecer recomendaciones de comida más personalizadas y adecuadas. Además, una interfaz sencilla y organizada facilitará su uso y mejorará la experiencia del usuario.
